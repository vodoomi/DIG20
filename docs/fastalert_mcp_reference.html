FASTALERT MCP 関数リファレンス

国内災害 fastalert_topics ▼
引数
categories 任意カンマ区切り。事故 / 火災 / 事件 / ライフライン / 気象・災害 / その他
locations 任意都道府県名・市区町村名（例: 石川県,石川県金沢市）
limit 任意最大件数 1〜100。デフォルト 30
order_by 任意created_at（デフォルト） / updated_at
after / before 任意ISO 8601。期間指定（created_at / updated_at ベース）
レスポンスフィールド
countint返却件数
head / tailstringページング用カーソル（before に渡すと次ページ）
topics[].idintトピックID（topic_detail / affected_user_locations に渡す）
topics[].headstringトピックタイトル
topics[].categorystring細分類（例: 車両火災、停電・電力設備トラブル）
topics[].is_hotbool短時間で投稿が集中している注目トピック
topics[].item_sizeint収集済み投稿件数
topics[].locationobject{ prefecture, city } 都道府県・市区町村
topics[].created_atstringトピック作成日時（ISO 8601）
topics[].items[]array投稿サマリー。id / head / category / created_at / published_at / url
⚠ items には添付画像・動画URLは含まれない。取得するには topic_detail を使う。
disasterバケット共有日300件 / 週1,500件 / 月3,000件
国内災害 fastalert_topic_detail ▼
引数
topic_id 必須topics[].id の値
レスポンスフィールド
id / head / category / location / created_at / updated_at / is_hot / item_size-topics と同様
items[].attachments[]array添付メディア。type（image/video）と image_url / video_url
📌 一覧との違いは attachments の有無。is_hot トピックの現場画像確認に使う。
disasterバケット共有 / 1呼び出し = 1件消費

気象・地震・津波 fastalert_weather_warnings ▼
引数
locations 任意都道府県名・市区町村名。未指定で全国（200件超になりやすいので推奨）
warning_kinds 任意大雨警報 / 大雨特別警報 / 土砂災害警戒情報 / 暴風警報 など。警戒レベル単位指定も可
limit 任意デフォルト 50
within_seconds / since+until 任意期間フィルタ（最大30日）
レスポンスフィールド
topics[].idstring警報トピックID（suffix付き）。weather_warning_detail に渡す
topics[].report_idstringsuffix無しID（現在発令中か解除済みかに関わらず最新状態を取得）
topics[].titlestring例: "熊本県気象警報・注意報"
topics[].headlinestring発表文（例: "注意報を解除します。"）
topics[].warnings[]array{ kind, status, level, prefecture, area_count, area_names[3件まで] }
topics[].date_timestring発表日時（ISO 8601）
ℹ since/until は「発令時刻の範囲」ではなく「その期間に有効だった警報」を返す。
disasterバケット共有

気象・地震・津波 fastalert_tsunami_alert_observations ▼
引数

海外ニュース fastalert_foreign_news ▼
引数
countries 任意ISO 3166-1 alpha-2 カンマ区切り（例: US,CN,PH）。keyword より高速・正確
keyword 任意原文・翻訳文の両方を全文検索。英語の方が精度高
categories 任意事故 / 事件 / 火災 / インフラ・ライフライン / 気象・災害 / 社会・政治的リスク / ヘルスリスク（これらの下位概念も指定可能（例えば、インフラ・ライフラインの下位概念としてサイバー攻撃））
kinds 任意news（デフォルト）/ official（USGS地震・各国気象）/ news,official
min_level 任意Lv1 / Lv2 / Lv3。newsトピックのみ適用（officialは常に含まれる）
min_supply_chain_impact_score 任意1〜5。SCM影響度スコアで絞り込み
only_supply_chain_impactful 任意true = 影響ありフラグのトピックのみ
min_magnitude 任意USGS地震トピックのみに適用するMの下限値
order_by 任意supply_chain_impact_score_desc（SCMスコア降順・単一ページ専用）
limit 任意1〜100。デフォルト 30
after / before 任意ISO 8601（updated_atベース）
レスポンスフィールド
topics[].idintトピックID（foreign_news_detail に渡す）
topics[].headstringニュースタイトル（日本語翻訳）
topics[].levelstring深刻度 Lv1〜Lv3（newsのみ。officialは省略）
topics[].supply_chain_impact_scoreintSCM影響スコア 1〜5（分析済みのみ）
topics[].is_supply_chain_impactfulbool影響ありフラグ
topics[].earthquakeobjectUSGSトピックのみ付与。{ lat, lng, magnitude }
has_more / tailbool/stringページングカーソル
foreign_newsバケット独立日300件 / 週1,500件 / 月3,000件
